---

JoiAsk 支持话题分类、图文投稿、内容审核与卡片归档。应用部署在 Cloudflare Workers，站点、管理后台和本文档共用同一域名。

<Callout type="warn" title="新安装没有默认管理员或默认密码">
  在 Cloudflare 部署表单中填写首个管理员的用户名和密码，发布后用这组凭据登录 `/admin/` 即可创建账号。也可用管理员 CLI 创建账号。[快速开始](./guide/quick-start.mdx)
</Callout>
