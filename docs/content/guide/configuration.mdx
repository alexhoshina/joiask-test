站点的 `wrangler.jsonc` 定义 Cloudflare 绑定。D1 的 `DB` 保存账号、问题、话题与设置。R2 的 `FILES` 存放头像、图片和表情。Durable Object `REALTIME` 向 WebSocket 与 SSE 客户端广播更新。消息队列 `MODERATION` 处理异步审核。

## 站点密钥

为 `SESSION_SECRET` 和 `SETTINGS_KEY` 分别准备至少 32 字节的独立随机值，保存为 Worker Secret。会话密钥用于登录状态，设置密钥保护 SMTP 密码和审核服务 API 密钥。本地开发时把单独的开发密钥填入根目录的 `.dev.vars`。请备份生产密钥，更换设置密钥后需要重新录入已加密的配置。

新站可在 Cloudflare 部署表单中填写首个超级管理员的用户名 `JOIASK_INITIAL_ADMIN_USERNAME` 和密码 `JOIASK_INITIAL_ADMIN_PASSWORD`。如果部署后在控制台手动添加，用户名可选 **Text** 或 **Secret**，密码选 **Secret**。首次用这组凭据登录 `/admin/` 后可移除这两项，同时保留上面的两个长期密钥。[首次部署与管理员](./deployment.mdx#首次部署与管理员)

## 内容审核

后台「设置」可以填写兼容 Chat Completions 的 HTTPS 服务基础地址、模型名称、API 密钥及垃圾投稿判定标准。保留现有密钥时留空即可；更换服务地址时需要重新提供密钥或清除已保存的密钥。设置只有管理员能够更新。

使用视觉模型时，在「内容审核服务」勾选「当前模型支持图片输入」并保存。首次启用或为新模型启用时，系统会先用测试图验证模型能读取图片。验证通过后，含图投稿的正文和配图会一起发送给所配置的模型。使用纯文本模型时，只发送正文和图片数量。

「视觉测试超时（秒）」默认是 20 秒，可设为 1 至 300 的整数。模型响应较慢时，可以在同一次保存中调长时间并启用图片输入。单独修改超时时间也可以保存，下次视觉测试会使用新值。

「审核自动公开」是单独的开关，默认关闭。开启并保存后，AI 判定正常的纯文字投稿会自动公开。含图投稿需要视觉模型读完所有配图并判定通过，使用纯文本模型时仍需管理员看图后公开。AI 判为低质量的投稿进入拦截箱，图片读取失败或审核最终失败的投稿留在收件箱。管理员已经处理的投稿保留人工决定。

## 用户注册与邮件

用户通过自己的 B 站 UID 和个性签名完成验证。后台可以启用「投稿需要已验证用户」。邮箱绑定和密码找回需要在后台启用并配置 SMTP，详见[投稿与邮箱](./usage.mdx)。

超级管理员可以在后台「设置」中修改「B 站用户资料接口地址」。签名验证和管理员手工创建会员都使用这个地址。新安装和从旧版本升级的站点默认使用 `https://api.bilibili.com/x/web-interface/card`。

如果你有自己的 HTTPS 反代，填写它提供的完整名片接口地址，例如 `https://bili.example.com/card`。用户输入 UID `12345` 时，Worker 会请求 `https://bili.example.com/card?mid=12345`。反代应保留查询参数，按 B 站原生名片格式返回 `code` 和 `data.card`，并关闭此接口的响应缓存，以便读到刚更新的签名。可先用自己的 UID 点击「测试连接」，核对昵称和签名后再保存。
